# Container Desk tutorial visual identity

## Style Prompt
A calm macOS tutorial using the user's Apple-inspired frosted-glass VM + Package identity. Fog-white backgrounds, slate typography, system blue used only for emphasis. Large readable captions and preserved real SwiftUI screen captures. Gentle crossfades and small movement, no simulated app success states.

## Colors
- #F3F4F8 — main background
- #1D2536 — primary text
- #526077 — secondary text
- #0067D9 — accessible blue accent
- #DCE3F0 — quiet glass borders and panels

## Typography
System SF / PingFang TC for Chinese and interface-like text; SF Mono for exact model IDs and technical quantities. Headlines 64–88 px, supporting copy 28–36 px. Weight contrast 750 versus 350. System fonts are rendered on the Mac, not distributed.

## Motion
0.5 s crossfades, 0.4–1.0 s entrances with restrained power/sine eases. Slow accent movement only; no busy ambient effects. Keep tutorial states readable for several seconds.

## What NOT to Do
- No invented downloads, progress bars, tool support or success messages.
- No host names, personal paths or unrelated containers.
- No neon, confetti, sharp flashes or elastic bouncing.
- No Apple logo or implication of endorsement.
- No video attachment in GitHub Releases; DMG-only remains the release policy.

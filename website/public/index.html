目前版本採 ad hoc 簽署，尚未經 Apple 公證。若 macOS 阻擋開啟，請依安裝教學處理。Apple Container 引擎需另外安裝。

你可能還想知道。

哪些 Mac 可以使用？+

需要搭載 Apple Silicon 的 Mac 與 macOS 26 以上系統。正式版在開發者自己的 M4 Mac mini 上，搭配 Apple Container 1.5.0 測試。

所有 Docker 專案都能直接搬移嗎？+

支援的 Compose 設定可匯入並檢查；Docker 本機映像檔與持久資料仍需另行搬移。選擇 ARM64 或 AMD64 架構不代表轉換二進位程式。

這是 Apple 官方的應用程式嗎？+

Container Desk 是獨立開發、採 Apache-2.0 授權的開源應用程式，用來管理 Apple 官方的 Container 引擎。

你可能还想知道。

哪些 Mac 可以使用？+

需要搭载 Apple Silicon 的 Mac 和 macOS 26 及以上系统。正式版在开发者自己的 M4 Mac mini 上，搭配 Apple Container 1.5.0 测试。

所有 Docker 项目都能直接迁移吗？+

支持的 Compose 配置可导入并检查；Docker 本地镜像与持久数据仍需单独迁移。选择 ARM64 或 AMD64 架构不代表转换二进制程序。

这是 Apple 官方的应用程序吗？+

Container Desk 是独立开发、采用 Apache-2.0 许可的开源应用程序，用于管理 Apple 官方的 Container 引擎。

A little more to know.

Which Macs are supported?+

Apple Silicon Macs running macOS 26 or later. The public release was tested with Apple Container 1.5.0 on the developer’s own M4 Mac mini.

Can every Docker project move over?+

Supported Compose settings can be imported and reviewed. Local Docker images and persistent data need separate migration. Selecting ARM64 or AMD64 is not binary conversion.

Is Container Desk an Apple product?+

No. Container Desk is an independent, Apache-2.0 open-source application that manages the official Apple Container engine.
